Kaggle datasets, Python implementations, data preprocessing, machine
learning algorithms, model training, and evaluation results.

- Linear Regression
- Logistic Regression

- Decision Tree
- Model Evaluation

- Pandas
- NumPy
- Matplotlib
- Scikit-learn
